# EDGE AUTO — Workspace operacional

Este é o workspace operacional do projeto **EDGE AUTO — Medição, Faturamento e Cobrança** (Adapta Native).

## O que existe aqui

| Pasta/arquivo | Para que serve |
|---|---|
| `01_projeto/` | Constituição do projeto (decisões acordadas) e objetivo/visão |
| `02_reunioes/` | Ata de corte do kickoff e atas liberadas |
| `03_documentos/` | Documentos públicos do projeto |
| `04_fase-atual/` | **Onde a acontece**: `fase.md` (tasks da fase) + `specs/` (contratos detalhados) |
| `05_entregas/` | Entregas aprovadas por fase |
| `06_notas/` | Debug e aprendizado contínuo |
| `STATUS.md` | Estado atual em uma tela |
| `changelog.md` | Histórico de mudanças |

## Como trabalhamos (Jornada de Execução)

1. Abra `04_fase-atual/fase.md` — cada linha é uma task da fase atual.
2. Executamos **uma task por vez**, na ordem das levas. Cada task só fica `[x]` depois das provas e do **teste humano**.
3. Toda task tem sua SPEC em `04_fase-atual/specs/` — é o contrato do que deve funcionar, com critérios de aceite e provas.
4. As perguntas de insumo (informações que precisamos de vocês) vão **junto com a task** — respondam no próprio card e a execução continua.

## Regras de ouro

- Nada de dado real antes da política de dados aprovada — demonstrações em dados sintéticos.
- Cálculo de horas faturáveis é **fail-closed**: sem teto contratual provado, nada sai como faturável.
- Decisões de ponto, divergência, liberação, NFS-e e call off são **sempre humanas**.
- Toda alteração de valor/horas/previsão fica auditada (quem, quando, por quê).
